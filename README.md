# 財富帝國 V19.9.21 WEB

這是《財富帝國》desktop / iPhone 網頁發布版。

## 本版
- 修正好友誤按重新整理後無法順利回到原本遊戲座位的問題。
- Guest 成功加入後，房號會寫回目前網址；重新整理後仍知道要回哪一個好友房。
- Guest 的座位、resume token、玩家名稱、最後事件 ID 會保存在該瀏覽器，續連資料最長保留 12 小時。
- 重新載入時，若網址房號有對應的有效 resume token，會自動接回房主與原座位，不需要再次輸入房號或按加入。
- 保存 lastEventId，重整後不再從第 1 筆開始重播整局歷史事件；只處理斷線期間真正新增的事件。
- 舊版 resume 資料若沒有 lastEventId，首次升級續連會直接以當前快照建立事件基準。
- 房主明確拒絕失效續連憑證時，會清除該房的 guest resume，避免無限重試。
- 保留 V19.9.20 股票持倉損益可視化。
- 保留 V19.9.19 Q 版操作按鈕整體重做。
- 本版處理 Guest/朋友重新整理；房主整頁重新整理仍需要另外做 Host Authority State 持久化。
- V19.9.15 持續固定為安全回退版：safe-rollback-v19.9.15。

正式頁面使用 APP_BUILD_ID 19921。
