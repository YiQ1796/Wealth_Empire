# 財富帝國 V19.9.39 WEB

《財富帝國 / Wealth Empire》desktop / iPhone 多人網頁版。

## V19.9.39｜方案 B：核心重整＋策略深化

- 四大主操作固定為「擲骰子／我的房產／策略道具／市場操作」。
- 四大主操作移除舊 sprite / ICON render source，暫以乾淨文字色塊呈現；後續新素材只替換 Asset Mapping。
- 「我的房產」成為唯一房產管理入口：土地列表、購入價、建設投入、目前估值、升級、收租紀錄、區域完成度集中處理。
- 區域壟斷正式生效：完整持有同區地產後，該區一般地產租金 +25%，失去完整持有即取消。
- 房產租金公式統一為：基礎租金 → 等級倍率 → 區域壟斷 → 市場事件 → 最終取整。
- 策略道具擴充至 8 種核心用途，保留「符合條件主動詢問、玩家可拒絕、不自動消耗」原則。
- 新增重新擲骰券、指定步數券、股票避險券、租金增幅券。
- 市場操作整合目前市場事件、持股數、均價、市值、未實現／已實現損益與股票買賣。
- 棋盤與股票建立有限度連動：地產升級與區域壟斷會影響對應產業，單回合設上限並阻止同回合自買自拉套利。
- 市場事件改為「房市熱潮／科技熱潮／經濟衰退／能源危機／觀光旺季」，事件具持續 Round 與房產／股票效果。
- 移除「30 格連消轉盤／金幣雨／吃麵大賽」的正式觸發；棋盤原轉盤與吃麵格改為「綠燈反應王／猜拳擂台」。
- 玩家自由交易維持取消。
- 角色技能已確認不存在於目前正式程式，不重新加入。
- 保留 Host Reload Recovery、Guest reconnect、heartbeat 與 P2P 續連機制。

## 安全與回退

- 開工基準：V19.9.38
- 安全回退分支：safe-rollback-v19.9.38
- 本版仍以 main 為 GitHub Pages 正式發布來源。

## 重要規則

- 新素材是「替換 render source」，不是疊在舊 UI / 舊 ICON 上。
- 短局／快速局本階段不做。
- 不重新加入角色技能、玩家自由交易、獨立升級地產入口或已移除的小遊戲。
